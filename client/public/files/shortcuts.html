Shortcuts

Toolbar

Action Keyboard (Mac / Windows)
Pins / Unpins the toolbar Cmd+Shift+M / Ctrl+Shift+M
Closes the toolbar and any submenus (e.g. font color) Escape

Essentials

Action Keyboard (Mac / Windows)
Copy Cmd+C / Ctrl+C
Cut Cmd+X / Ctrl+X
Paste Cmd+V / Ctrl+V
Paste without Formatting Cmd+Shift+V / Ctrl+Shift+V
Undo Cmd+Z / Ctrl+Z
Redo Cmd+Shift+Z / Ctrl+Shift+Z
Line Break Shift+Enter or Cmd+Enter / Shift+Enter or Ctrl+Enter

Text Formatting

Action Markdown Keyboard (Mac / Windows)
Bold **text** or __text__ Cmd+B / Ctrl+B
Italic _text_ or *text* Cmd+I / Ctrl+I
Underline — Cmd+U / Ctrl+U
Strike-through ~~text~~ Cmd+Shift+S / Ctrl+Shift+S
Cycle Font Color — Cmd+Shift+C / Ctrl+Shift+C
Cycle Heading Level — Cmd+Shift+H / Ctrl+Shift+H
Cycle Text Alignment — Cmd+Shift+A / Ctrl+Shift+A
Cycle Line Spacing — Cmd+Shift+P / Ctrl+Shift+P
Inline Code `code` Cmd+E / Ctrl+E
Clear Format — Cmd+Shift+0 / Ctrl+Shift+0

Paragraph Formatting

Action Markdown Keyboard (Mac / Windows)
Normal Text — Cmd+Opt+0 / Ctrl+Alt+0
Heading 1 # Heading 1 Cmd+Opt+1 / Ctrl+Alt+1
Heading 2 ## Heading 2 Cmd+Opt+2 / Ctrl+Alt+2
Heading 3 ### Heading 3 Cmd+Opt+3 / Ctrl+Alt+3
Heading 4 #### Heading 4 Cmd+Opt+4 / Ctrl+Alt+4
Heading 5 ##### Heading 5 Cmd+Opt+5 / Ctrl+Alt+5
Heading 6 ###### Heading 6 Cmd+Opt+6 / Ctrl+Alt+6
Ordered List 1. item Cmd+Shift+7 / Ctrl+Shift+7
Bullet List - item or * item or + item Cmd+Shift+8 / Ctrl+Shift+8
Indent List Item — Tab
Outdent List Item — Shift+Tab
Blockquote > quote Cmd+Shift+B / Ctrl+Shift+B
Code Block ```language``` Cmd+Opt+C / Ctrl+Alt+C
Divider --- —
Link [text](https://example.com) Cmd+K / Ctrl+K
Align Left — Cmd+Shift+L / Ctrl+Shift+L
Align Center — Cmd+Shift+E / Ctrl+Shift+E
Align Right — Cmd+Shift+R / Ctrl+Shift+R
Justify — Cmd+Shift+J / Ctrl+Shift+J

Text Selection

Action Keyboard (Mac / Windows)
Select All Cmd+A / Ctrl+A
Extend Selection Left Shift + ←
Extend Selection Right Shift + →
Extend Selection Up Shift + ↑
Extend Selection Down Shift + ↓
